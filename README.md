# Digital Communication System Simulation (MATLAB)
This repository contains a MATLAB simulation of a baseband equivalent digital communication system, implemented as part of the COMM.SYS.400 Digital Communications course (2022–2023). The system models the full transmission chain, including modulation, pulse shaping, channel effects, noise, receiver processing, equalization, and error control coding.

🔧 Features
M-QAM / M-PSK modulation and Gray mapping

Transmitter with square-root raised cosine (RRC) pulse shaping

Multipath fading channel with adjustable SNR

Matched filtering and symbol synchronization

Adaptive LMS equalizer implementation

Minimum distance symbol detection

Hamming (7,4) block coding for error control

Bit Error Rate (BER) computation and analysis over varying SNRs

Eye diagrams, constellation plots, and frequency response visualizations

📁 Contents
Main simulation script

Plots: Eye diagrams, constellations, BER vs. SNR curves

Comments and annotations to explain each stage of the system

📘 Requirements
MATLAB (R2018a or newer recommended)

Signal Processing Toolbox

🎓 Purpose
This project was designed to help understand and implement essential components of digital communication systems. It demonstrates the effects of filtering, channel distortion, noise, and the use of equalization and error correction in modern communication pipelines.
